# 技能设计文档：法师瞬移 (Teleport)

## 1. 技能概述

- **技能名称**：瞬间移动 (Teleport)
- **核心定位**：法师职业的基础位移技能，赋予脱战机动性与跨地形能力。
- **感官表现**：角色在原地瞬间消失，立刻出现在前方指定距离处。

## 2. 基础规则

- **移动方式**：沿角色当前面位的水平方向，瞬间位移固定的 `150像素`。
- **落脚判定**：不计算“飞行轨迹”，直接在目标点进行**向下地面探测**。寻找到最近的合法地面后，直接将角色吸附过去。

## 3. 地形与边界交互 (Edge Cases)

为了保证玩家操作的“丝滑感”并杜绝恶性 Bug，该技能在特殊地形下的判定规则如下：

### 🟢 允许判定的情况 (通行无阻)

- **【穿墙与越障】**：**无视路径碰撞**。不论中间阻隔的是薄墙、紧闭的房门还是树木，只要目标位置（障碍物后方）存在合法的水平地面，即可无缝穿透。
- **【斜坡与台阶】**：**智能高度宽容**。允许目标地面的高度与当前高度存在一定落差（落差容错值上下约 `100 px`）。玩家在上坡或下坡时连续按下瞬移，角色将像“贴地滑行”般平顺跳跃，不会被地面台阶卡顿。

### 🔴 拒绝判定的情况 (原地施法失败)

- **【绝壁阻挡】**：如果目标地点的地面高度远超当前高度（高差 `> 100 px`），视为难以逾越的高墙，传送指令拒绝。
- **【深渊防坠】**：如果传送的目标水平位置无可站立的地板（如面对断崖、虚空），传送指令拒绝。
  > **设计目的**：宁可让玩家原地停滞，也绝对不允许利用穿墙机制跨出地图边界或坠入深渊。
